# 演示脚本：客群资产结构透视（客群诊断分析 Skill）

> 用途：录制「一句话圈选 → 核验 → 统计人数 → 选技能与标签 → 选对照客群 → 诊断报告」完整闭环。
> 版本：v1.0（2026-09-30）；对应代码分支 `merge/v4.0-merge-skill-engine`（未提交工作区）；技能包 `diagnostic-analysis v1.2.0`。
> 数据底座：标签库「个人客户经营标签库」（107），快照 `L107-20260928-006`，宽表 2,000 人。
> 本脚本已按真实模型彩排两次：圈选一次通过无需澄清；诊断运行约 90–130 秒完成，报告 3 张卡 + 4 张图全部通过服务端与前端校验。

---

## 一、录制前检查（约 3 分钟）

1. 服务状态（应五项全 running）：

```bash
./dev.sh status
```

2. 打开工作台：标签系统菜单进入智能圈选（Vue 路由 `/agent`，内嵌 `tagpilot-assistant`），登录账号 `admin`。
3. 确认左侧标签库为「个人客户经营标签库」。
4. 对照客群已在库中：对象群列表可见「全量客户（资产结构基准）」（2,000 人）——本脚本的对比基准，**演示时不需要现场创建**。
5. 打开本文件的「附录 A 对账表」放在手边，报告出数时逐项核对。

---

## 二、录制步骤

### 第 1 步 圈选客群（约 0:00–1:00）

1. 对象群列表 → 点「继续圈选」（或工作台「新建圈选」）。
2. 输入框**逐字**输入圈选提示词：

> 当前AUM月日均余额50万元及以上的客户

3. 等待 Agent 生成方案（约 10–20 秒）。右侧「圈选方案」应显示一条条件：**当前AUM月日均余额 ≥ 500000（元）**，无待确认问题。
4. 点方案下的核验按钮，顶部状态变为「条件已核验」。
5. 点「统计人数」→ 显示 **287 人**。

> 若出现澄清问题或人数不是 287：不要继续录制，按第 4 节排查（提示词已彩排为一次通过）。

### 第 2 步 选技能、标签与对照客群（约 1:00–1:50）

1. 输入框敲 `/` → 选择「**客群诊断分析**」（技能名 `diagnostic-analysis`）。
2. 左栏切到「标签」，逐个搜索并勾选（共 5 个，已达上限）：

   | # | 标签名 | 口径 |
   |---|---|---|
   | 1 | 当前时点AUM | 元 |
   | 2 | 当前固收类AUM占比 | % |
   | 3 | 当前权益类AUM占比 | % |
   | 4 | 当前现金类AUM占比 | % |
   | 5 | 当前潜力资产等级（规则预测） | 六档分布 |

   点「加入输入框」（标签作为 chip 进入输入框上方）。
3. 技能名下方出现「**对照客群**」下拉框，选择「**全量客户（资产结构基准）（2000 人）**」。

### 第 3 步 输入分析目标并运行（约 1:50–3:40）

输入框**逐字**输入：

> 对本客群做资产结构透视：看当前时点 AUM 的规模与分布、固收/权益/现金三类资产的占比结构、潜力资产等级分布，并与对照客群比较，指出值得关注的结构特征与方向。按行内资产配置检视口径：权益类资产占比低于 10% 视为权益配置不足；现金类资产占比高于 50% 视为流动性超配。

发送后运行约 **90–130 秒**（对话区可见「正在调用关联技能 / 正在读取技能参考资料 / 正在整理已确认的条件」，属正常过程，可保留在镜头里）。等待期间不要重复发送。

### 第 4 步 查看报告（约 3:40–5:00）

运行完成后右栏自动切到「洞察」页。预期内容见附录 B：
- KPI：客群规模 287 人；
- 3 张五段式卡片（事实 / 对比 / 诊断·规则 / 行动 / 证据与边界），诊断依据均为「规则」；
- 3 张对比图（AUM 分布、三类资产占比、潜力等级分布），每张均叠加「本客群 vs 全量客户」两组系列；
- 页脚「建议下一步」4 条检验方向。

可演示的收尾动作（任选其一，各 10–20 秒）：
- 展开任意卡片的「查看证据与口径」：显示数据日期、Skill 版本 1.2.0、包 hash、快照 `L107-20260928-006`；
- 点「复制本段摘要」导出带版本与边界的文本。

## 三、口播要点（可选，30 秒版）

> 这条客群由一句话圈选产生，条件、人数和五个标签的统计全部由服务端核验后注入模型；模型只能引用这些数字，改一个数就会被丢弃。我们选了「全量客户」作为对照客群，报告里每个差异都能用两张服务端统计表复算——比如权益类占比均值只有 2.67%，比全量高 0.95 个百分点，但按行内「低于 10% 视为权益配置不足」的口径，这群中高价值客户仍然整体低配。报告不给结论式猜测：没有检验的一律标为观察，无法下钻的维度如实写在边界里。

## 四、应急与排查

| 现象 | 处理 |
|---|---|
| 圈选出现澄清问题 | 正常流程，按选项回答（如「当前AUM月日均余额」的口径）；如需重录，重新发一遍提示词 |
| 统计人数 ≠ 287 | 检查方案条件是否为「当前AUM月日均余额 ≥ 500000」；若条件一致而人数不同，说明宽表数据变了，更新附录 A 后再录 |
| 技能运行超过 3 分钟 | 本轮上限约 150 秒会自动收尾；若失败，重新选择技能发送一次即可（预算与并发均未占用） |
| 报告为空 / 卡在「正在展开报告」 | 切到「圈选方案」再切回「洞察」；仍为空则说明技能输出未过校验，重跑一次 |
| 对照客群下拉为空 | 确认标签库选对（107）且对象群「全量客户（资产结构基准）」未被删除；该下拉只列出与当前发布版本一致的已保存客群 |

## 附录 D 进阶复杂语句（已逐条实测，同一技能与对照客群）

> 每条给出**口语版**与**稳妥版**：口语版已实测零澄清可直接念；一旦把「口径词、完整标签名、超配/异名跨行转入这类术语」口语掉（如"月日均资产"、"存款占AUM"、"配置偏多"、"潜力等级"），系统会先反问口径——那是受控澄清，不是错误，但录制时会多一步。

以下语句均提交真实圈选 Agent 验证（2026-09-30）：除标注外一次通过、零澄清，人数为宽表实测。分析目标语句沿用同一「透视 + 对照 + 检视口径」模板；对照客群统一选「全量客户（资产结构基准）」，分析列 ≤5 个。

**① 存款集中且未持有理财（派生比率 + 布尔）｜139 人**


> **口语版（可直接念）**：帮我圈一批人：当前AUM月日均余额50万以上、当前存款余额占当前AUM月日均余额八成以上，而且当前没持有理财产品
> **稳妥版（逐字可核验）**：当前AUM月日均余额50万元以上、当前存款余额占当前AUM月日均余额八成以上、且当前未持有理财产品的客户
>
> 分析：对本客群做资产结构透视：看当前时点AUM分布、固收/权益/现金三类占比与潜力资产等级分布，并与对照客群比较。按行内资产配置检视口径：权益类资产占比低于 10% 视为权益配置不足，现金类资产占比高于 50% 视为流动性超配；指出值得关注的结构特征与方向。

分析列建议：当前时点AUM、固收/权益/现金占比、近12个月最高AUM（潜力等级在该客群有两档不足 20 人，会被抑制，勿选）。

**② 资产回撤（跨期复合表达式）｜74 人**


> **口语版（可直接念）**：帮我圈一批客户：过去一年资产最高到过50万以上，现在比最高点缩水超过一成
> **稳妥版（逐字可核验）**：近12个月最高AUM在50万元以上、当前时点AUM比近12个月最高AUM缩水超过一成的客户
>
> 分析：对比本客群与对照客群：看当前时点AUM的分布、固收/权益/现金三类占比结构与潜力资产等级分布，指出缩水客群的结构特征与差异方向。按行内口径：权益占比低于 10% 视为权益配置不足、现金占比高于 50% 视为流动性超配。

生成表达式：`(近12个月最高AUM − 当前时点AUM) ÷ 近12个月最高AUM > 0.1`。分析列建议：当前AUM月日均余额、固收/权益/现金占比、当前存款余额。**注意**：本句为跨期口径，实测 3 次中 2 次一次通过；若出现「本轮处理次数已达上限，已保留当前方案」，原句再发一次即可。

**③ 配置失衡（布尔标志 OR）｜264 人**


> **口语版（可直接念）**：帮我圈一批人：当前AUM月日均余额30万以上，而且是固收或者现金超配的客户
> **稳妥版（逐字可核验）**：当前AUM月日均余额30万元以上，且固收类资产超配或现金类资产超配的客户
>
> 分析：对本客群做结构透视并与对照客群比较：三类资产占比、AUM 分布、潜力资产等级分布；核对「超配」标志与占比结构的一致性。按行内口径：权益类资产占比低于 10% 视为权益配置不足。

分析列建议：当前时点AUM、固收/权益/现金占比、当前持有理财标志。

**④ 事件窗口 + OR 组合｜245 人**


> **口语版（可直接念）**：帮我圈一批客户：最近30天有异名跨行转入、当前AUM月日均余额20万以上，而且在「潜力资产等级300万以上」和「现金超配」两条里满足一条就行
> **稳妥版（逐字可核验）**：近30天有异名跨行转入、当前AUM月日均余额20万元以上，且潜力资产等级在300万元及以上或现金类资产超配的客户
>
> 分析：对本客群做资产结构透视并与对照客群比较：三类资产占比、AUM 分布、潜力资产等级分布。按行内口径：权益占比低于 10% 视为权益配置不足、现金占比高于 50% 视为流动性超配；指出值得关注的差异方向。

分析列建议：当前时点AUM、固收/权益/现金占比、当前持有理财标志（若把「潜力资产等级」选为分析列，它已被圈选条件截断，报告会声明口径影响）。
