## 一、服务拓扑

| 进程 | 技术栈 | 监听 | 归属 | 主要职责 |
| :--- | :--- | :--- | :--- | :--- |
| `ruoyi-admin` | Spring Boot 2.5 / Java 8 | `8080`（默认） | 原系统 + 智能层 Java 侧 | 登录鉴权、权限判定、长期会话持久化、人数统计与客群创建、语义层治理 UI 后端 |
| `tagpilot-semantic` | FastAPI | `127.0.0.1:8091` | 智能层 | 快照加载、索引构建、多路召回与重排、证据与能力检索 |
| `tagpilot-agent` | FastAPI + Claude Agent SDK | `127.0.0.1:8092` | 智能层 | 圈选工作台运行编排（澄清/修复/取消）、洞察计划与运行、图表改图 |
| `tagpilot-insight` | Python 库（无独立端口） | — | 智能层 | Skill 注册表、指标与图表合成，被 `tagpilot-agent` 进程内导入 |
| `tagpilot-assistant` | React（Vite） | `127.0.0.1:5174`，路径 `/agent-ui/` | 智能层前端 | 对话工作台；由 Vue 的 `/agent` 路由 iframe 嵌入 |
| Milvus / MySQL / Redis | 基础设施 | — | 原系统 + 智能层 | 语义层索引集合（MILVUS 模式）、业务库、JWT 会话与缓存 |

调用方向固定为单向：**浏览器/Assistant → Java → Python**。两个 Python 服务不回连 Java，也不接受用户直连（端口绑在本机回环）。Java 侧不信任任何客户端传入的服务地址，目标地址只从运维配置读取。

## 二、认证与鉴权

| 链路 | 机制 | 凭据载体 | 失败语义 |
| :--- | :--- | :--- | :--- |
| 浏览器 / Assistant → Java | 无状态 JWT | `Authorization: Bearer <token>`，token 为 Redis 中 `login_tokens:<uuid>` 的 UUID | 缺失或过期 401，前端跳登录 |
| Java → Python（两个服务） | 共享服务令牌，常量时间比较（`hmac.compare_digest`） | `Authorization: Bearer <TAG_RUNTIME_TOKEN>` | 令牌未配置 503；不匹配 401 |
| 行级权限 | Java 侧 `@PreAuthorize("@ss.hasPermi('...')")` | 登录用户权限集（Redis 缓存） | 403 |
| 会话归属 | `owner_id` = 登录用户 `userId`，由 Java 注入，前端不可指定 | 请求体字段 | Python 侧 404（越权访问他人运行） |

要点：

1. **`owner_id` 必须由服务端注入**。Java 一律以 `SecurityUtils.getUserId()` 填充，Python 侧按 `(run_id, owner_id)` 取运行，查不到即 404，因此越权读取他人会话在协议层无法表达。
2. 两个 Python 服务共用同一个 `TAG_RUNTIME_TOKEN`；Java 侧配置项为 `tag.runtime-token`。
3. `tagpilot-agent` 的长期会话**不落 Python**：Python 只保存短期运行记录（加密 SQLite），长期会话状态加密存于 Java 的 `ts_agent_thread`。删除会话时 Java 先级联调 `DELETE /agent/v2/threads/{id}`。

## 五、Python 语义引擎 `:8091`

所有接口除 `/health` 外均要求 `Authorization: Bearer <TAG_RUNTIME_TOKEN>`。

| 方法 | 路径 | 请求模型（关键字段） | 响应要点 |
| :--- | :--- | :--- | :--- |
| GET | `/health` | — | `{status, configured}`，无鉴权 |
| POST | `/bootstrap/expand` | `jsonl`（≤20 MB） | 展开为可导入草稿 |
| POST | `/build` | `build_id`、`snapshot_id`、`library_id`、`store_type` ∈ LOCAL/MILVUS、`retrieval_config` | manifest + `artifact_uri` + `artifact_hash`；**读超时 600 s** |
| POST | `/retrieve` | 基座字段 + `requirement` ≤500、`k` ∈ 1–50、`mode` ∈ fast/deep | 候选 + 特征；`auto_execute` 恒 `false` |
| POST | `/lookup` | 同上 | 只读目录与 AC 索引，不触发向量检索与重排；含 `terms` |
| POST | `/retrieve_batch` | 基座 + `queries` 1–8 条，**同一 build 与 eligible 租约** | `{results: [...]}` |
| POST | `/evidence` | 基座 + `tag_ids` ≤50、`value_query` ≤200、`max_values` 1–30 | 口径/码值/族成员证据；资格外标签 403 |
| POST | `/capabilities` | 基座 + `capability_ids` ≤20 | 能力候选 + 其输入标签上下文 |
| GET | `/stats?build_id=` | — | 行集对账 `id_reconciled` |
| POST | `/catalog-overview` | 基座 | 标签/概念/域计数 |
| POST | `/activate` | `build_id`、`snapshot_id`、`library_id`、`store_type` | 激活前强制行集对账，失败 409 |
| POST | `/deactivate` | 同上 | `alias_removed` |
| POST | `/drop` | 同上 | 保留快照与 manifest，仅移除派生 Collection；`purged.json` 标记 |
| GET | `/metrics` | — | 计数与缓存构建数 |

「基座字段」指 `requirement`、`library_id`、`build_id`、`eligible_tag_ids`（≤100000）四件套；检索类接口均据此校验 `build` 与库、资格的一致性，不一致返回 409。

硬约束（来自服务实现，属对外契约的一部分）：

- 响应中 `auto_execute` 恒为 `false`，`decision` 恒为 `CANDIDATES_ONLY` —— **语义层只给候选，永不自动执行**。
- 只回传可见候选与可观测特征，不回传向量或含隐藏成员的完整目录对象。
- 检索失败返回 503 且**不降级**（"检索服务暂不可用；未降级"），避免用降级结果冒充正常结果。
- 每请求返回 `trace_id`、`snapshot_id`、`artifact_hash`、`eligible_hash`，用于复核。

## 八、关键请求契约

### 8.1 `RunRequest`（Java → `POST /agent/v2/runs`）

| 字段 | 约束 | 说明 |
| :--- | :--- | :--- |
| `run_id` | `^[a-zA-Z0-9-]{1,64}$` | Java 生成 UUID |
| `thread_id` | 同格式 | 会话标识 |
| `owner_id` | 1–64 字符 | 服务端注入的 `userId` |
| `library_id` / `build_id` / `snapshot_id` / `artifact_hash` | 正整数 / 格式串 | **运行绑定到确定 build 与制品哈希**，防止运行中途换索引 |
| `eligible_tag_ids` | ≤100000 | 资格集合 |
| `pinned_tag_ids` / `pinned_only` | ≤5，须唯一且属于 eligible | 左栏多选标签上下文；`pinned_only` 时必填 |
| `requirement` | 1–2000 字 | 自然语言需求 |
| `reference_date` | `^\d{4}-\d{2}-\d{2}$` | 相对时间基准 |
| `timezone` | ≤64，默认 `Asia/Shanghai` | — |
| `previous_plan` / `source_plan` / `edited_plan` | 对象 | 迭代与人工改图 |
| `history` | ≤20 条 | 对话历史 |
| `confirmed_clause_ids` | ≤30 | 人工已确认条件 |
| `clarification_state` | `records` ≤20、`pending_questions` ≤3 | 澄清状态机载体 |
| `continuation_of` | 格式串 | 续跑来源，须属同一会话 |

请求模型 `extra='forbid'`：出现未声明字段直接 422。`resume`/`repair` 另有 `eligible_tag_ids` 交集收窄逻辑：运行中资格被收回时，`eligible` 只减不增。

### 8.2 洞察计划与报告

- `POST /agent/insight/plan` 入参 `cohort`（客群快照）+ `bindings`（≤60）+ `eligible_tag_ids`；返回 `MetricPlan`，含 `status`（READY/BLOCKED）、`skill_version`、`pack_hash`。
- `POST /agent/insight/runs` 入参 `plans`（1–3）与 `aggregates`（≤3）：**同一运行内所有计划必须同客群快照且技能不重复**，否则 422。
- 报告 `InsightReport` 结果项状态：`BLOCKED` 时带 `level=L4` 与 `reasons`；部分可用为 `L2`。`BLOCKED` 技能不消耗聚合数据。

## 九、错误语义对照

| HTTP | 语义 | 典型触发 |
| :--- | :--- | :--- |
| 401 | 未认证/令牌不匹配 | Java token 过期；Python 服务令牌错误 |
| 403 | 权限不足 | Java `@PreAuthorize` 或服务内二次校验；`/evidence` 传入资格外标签 |
| 404 | 运行不存在或无权访问 | `(run_id, owner_id)` 不匹配 |
| 409 | 状态冲突 | 构建不属该库、激活身份不一致、运行不可恢复、洞察需重新运行、修复次数耗尽 |
| 422 | 参数非法 | 未声明字段、空澄清回答、字数/数量越界、改图需求超范围 |
| 429 | 并发/队列满 | 编排层准入拒绝 |
| 503 | 依赖不可用或未配置 | 令牌未配置、索引校验失败、检索失败（**不降级**）、运行库被占用 |

## 十二、未接入与已知缺口
