# Agent V2 与圈选工作台开发计划

依据：用户提供的 Agent V2.md、2026-09-21 前台评审、现有 Java/Python/React 实现。

## 交付边界

保留 Java 身份、授权和实际执行边界；保留旧单次检索 API。新增版本化圈选任务、持久化消息与过程、真实 Ask/计划/标签绑定、多轮修订、只读人数统计及用户确认后的幂等创建。界面使用白色/浅灰与系统主题。不得把离线测试当真实模型效果或业务验收。

## 一致性原则

一个会话固定一个标签库。消息与方案自动保存；正式创建必须确认当前 revision/hash。修改方案使人数与确认失效。Ask 绑定运行与条件；旧问题不可恢复新版本。统计结果包含执行时间，数据时点不可获取时显式未知。服务端校验每次访问与执行的当前权限。历史只读回放不重新调用模型。

## 最终验收记录（2026-09-21）

- Java：205 项通过（databroker 29、objectgroup 62、taglibrary 114），包含新编译器嵌套逻辑、版本/资格、单位/时间、权限、旧版本拒绝、取消及建群幂等测试。
- Agent Python：11 项通过，包含加密检查点重启恢复、事件游标、归属、幂等、停止、单位/时间及未知码策略。
- 语义接口：15 项通过，1 项因未提供跨语言导出夹具跳过；新增固定发布证据权限/版本测试通过。
- React：8 项通过；Playwright 4 项通过，覆盖修改失效/刷新恢复/明确创建确认、Ask、窄屏、样例键盘模态、错误反馈及历史入口。
- Maven 打包、React 生产构建、Vue 生产构建通过。React 主包约528 kB，构建保留大包提示；未通过抬高阈值隐藏提示。
- 真实本地登录、持久会话、模型检索绑定、多轮追加条件、Java 编译和只读统计验证通过；最终服务重启后会话、消息和版本恢复正常。第一版有效方案统计1422人；后续增加金额条件后旧人数失效。
- 独立界面评审初审为 fix，五项修复复审均 resolved，disposition ship，范围限该修复清单。

实现不等于银行业务验收：未进行独立 A/B/C 大样本准确率评测；未在业务库试做真实客群创建；单服务进程 SQLite 的部署边界详见[实施说明](Agent-V2实施说明.md)。本次仅运行本地新增迁移，无生产部署、Git 提交或推送。
