# 圈选工作台界面方向

继承 PRODUCT.md 的企业后台约束，按用户指定的 assistant-ui 官网简洁工作台风格完成代码实现。采用白底、浅灰分区、细边框与若依主题强调色，不增加独立的装饰性品牌。

桌面首屏以历史会话、对话过程、当前圈选方案分栏。方案栏在对话滚动时保持可见，条件按业务逻辑树组织，条件值显示中文单位和码值；数值倍率不能隐藏。窄屏通过历史、对话、圈选方案三个标签页切换。主要交互是“描述条件—核对口径—补充问题—修改方案—统计人数—明确确认创建”。

运行中的真实工具事件驱动进度，未完成步骤不得显示完成。Ask 使用输入与选项，停止后保留已有条件；历史版本只读，可恢复为新版本。人数绑定当前方案，修改后失效。样例展示不进入模型上下文与会话。

交互控件保留键盘焦点，错误与状态用文字表达，尊重减少动态效果设置。验证视口：1440×960 和 390×844。合成浏览器测试数据仅用于界面状态测试，不构成真实模型效果或银行业务验收。
