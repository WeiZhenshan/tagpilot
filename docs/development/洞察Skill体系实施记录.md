## 架构与权威边界

浏览器只访问 Java。Skill 挂在当前工作台客群快照上，输入固定为方案 revision、plan hash、人数、snapshot、数据日期和绑定版本。圈选 Claude Agent SDK 的提示词与五个工具保持原路径，洞察使用独立 `profile=insight`。

Java 顺序执行：当前客群 / COUNT 校验 → 已发布注册版本与标签资格复核 → Python 声明式 plan → Java 白名单 SQL 聚合 → 现有 Agent 进程计算 / Guard → Java 再复核 → 加密保存报告与审计。G3 自动补跑 G2；基准、日期和绑定版本不一致时阻断。发布状态、权限、来源版本或方案在中途变化时丢弃整份旧结果。普通单技能不可用保留其他技能并记录 BLOCKED，不替换条件或返回合成数据。

`tagpilot-insight` 是独立 Python 库，导入现有 `tagpilot-agent`，不增加端口。复用 RunManager 的并发 / 用户准入、排队、取消、事件和加密 SQLite；洞察不支持圈选 resume / repair，需在当前快照重新运行。路由和改图也占用同一准入限额。Java 聚合预算 60 秒、单查询最多 30 秒；Python 子运行最多 60 秒，Java 等待 55 秒超时取消。尚未做整个三技能场景包的延迟或容量验收，不能据此承诺 P95。

## G1 / G2 / G3 固定数值验收

H2 内建立 800 人合成来源，客群为 240 人。Java `TsInsightQueryService` 执行生产聚合编译器，测试以 mocked 元数据 / 连接入口提供 H2，而非 fixture 直接生成运行事实。Python 仅接收 Java 输出的聚合结果。

| 技能 | 独立手算参考 | 结果 |
| --- | --- | --- |
| G1 | 240 人、总 AUM 120,000,000 元、均值 / 中位数 500,000 元、流动资产 60%、基准差 0pp | 逐项一致 |
| G2 理财 | 持有 60/240=25%、标准化基准 70%、缺口 45pp、机会人数 120；Wilson 95% 区间约 19.95%–30.84%，与基准区间不重叠 | 逐项一致，STAT 附可重算证明 |
| G3 | 硬排除后可营销 180 人；高 / 中 / 低 80 / 60 / 40；原因组合总人数 180 | 分档、贡献和原因组合对账 |

G3 的 180 人按整体营销资格计算，缺口分只赋给目标品类未持有客户；它与 G2 的“目标品类机会 120 人”是不同范围。高 / 中 / 低是并列分组，不串成漏斗。G3 不提供名单、建群或任务下发。

SQL 在 Java 内执行只读事务、白名单表列和有界查询；客户键非空唯一校验、当前在线来源版本复核、NULL 资格排除、小样本及互补格抑制都发生在输出前。每格 / 分量小于 20 时不下发精确值；G2 比较另要求两侧有效分层样本至少 30。缺适当性时保留持有覆盖事实，但取消机会判定并标 L2；无统计缺口时不进入 G3。

## 注册、缓存和管理

三个代码包仍为 `DRAFT / 0.1.0`，不意味着数据库已发布。包 hash 覆盖规范化 Manifest、库代码和 fixtures；任一变化使旧门禁失效。Java 的不可变注册版本、binding version、基准版本与定义 hash 分别记录治理配置，不能用包版本替代数据口径版本。

基准缓存位于 Java 内存，最多 64 项，默认 60 秒；`tagpilot.insight.benchmark-cache-seconds` 可设 0 禁用，最大 86400 秒。键包含用户、授权范围、库 / 在线来源版本、数据日、定义 / 版本、绑定、snapshot、包 hash 以及编译 SQL 的范围条件。复用前仍复核资格；没有跨用户 / 机构共享。一天 TTL 需业务确认数据日在当日不变及刷新规则后才能配置，本批不默认日缓存。

管理页入口由迁移新增 `/taglibrary/insight-skill` 菜单，权限分为 list、edit、review、publish、run，不自动授予业务角色。草稿只接收逻辑指标 / 标签 ID、治理转换、单位、码值映射、日期与版本，拒绝 SQL / 物理列 / 客户端伪造门禁。

“合成沙盒”只调用固定合成材料，明确告知未执行此注册版本的实际指标绑定、不改变复核 / 发布状态。实际绑定运行在工作台发布后执行。复核调用服务器固定包门禁，发布在标签库行锁内切换当前版本；旧代码 hash 的版本不能直接回滚到新代码包。

成功报告与 Java 审计在短事务内保存；运行状态区分 COMPLETED、PARTIAL、BLOCKED、FAILED。失败审计另存通用错误，不保存 SQL / 客户信息；列表限当前所有者最近 100 项。报告读取和编辑均重新检查发布状态、权限、版本、日期；前端方案变化后禁止复制、导出和修改。
