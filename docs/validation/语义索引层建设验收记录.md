## 与原方案的显式偏差

1. AC 持久化使用安全 JSON 词典重新构建 Aho-Corasick 自动机，不使用可执行反序列化的 pickle；词典文件纳入 hash。
2. Milvus `concept_id` 使用 VARCHAR，同时兼容离线稳定概念编码与 Java 数字 ID；不能将 Python 字符串编码硬塞入 INT64。
3. 发布完整度当前逐标签要求≥70，比“范围均分≥70”更严格；黄金场景≥90和赛前均分≥85仍待业务质量验收。
4. 增加 PURGED 终态表示派生 Collection 已清理；保留不可变产物，仅能以新 build 重建。
5. 没有预建自动降级副本。Milvus 故障明确失败，LOCAL 必须显式新建/激活，绝不混用模式。
6. 当前同源一致性读不等于跨来源全局事务。模型权重、封存测试集、业务复核及生产拓扑均不得以合成结果冒充。
