竞赛库快照配套机密（勿提交真实内容到公开仓库）

自 2026-09-30 起，以下两件已随 `bin/package-competition-zip.sh` 打出的 zip 一并交付，
评委解压后直接放在仓库根目录（与 dev.sh 同级）即可，无需另外索取：

1. .databroker-crypto-secret
   - 与快照内 dp_datasource 连接密码密文配对；缺失时须在「数据源管理」重新录入密码
   - zip 内文件权限为 600，分发时按加密通道/U 盘传递，勿投向公开仓库

2. .tag-runtime-token
   - Java 与 Python 服务间令牌；随包固定后评委本机 dev.sh 不再另行生成
   - 若删除该文件，评委端 dev.sh 会自动生成一份新的，功能不受影响

仍不随包交付：

3. .tag-llm-config
   - 含对话模型 API Key，评委自备（可参考 .tag-llm-config.example，脚本默认 DeepSeek 官方端点）

注意：以上两件均属**本地演示凭据**。对外正式分发或用于生产前，请替换 .databroker-crypto-secret
（需同步更换库内数据源密码密文）并轮换 .tag-runtime-token。
