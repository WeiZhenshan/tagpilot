# 客群圈选 Agent 自然语言测试案例（A01–K08）

依据《业务分析场景完整清单》v2 实算（快照 **2026-09-18**，2,000 名模拟客户）。本文件只提供**可贴进圈选工作台的用户原话**，用于验收 Agent 把业务口述编译成圈选方案的能力。

圈选 Agent 的任务是拆解条件、绑定发布标签、校验口径并统计人数；不是做资产透视或机会排序分析。金标准人数只写在评测栏，**不要写进输入**。人数为 0 时不得自动放宽条件。

数据与口径见同目录《业务分析场景完整清单》《业务分析场景速查表》。近 30 天为 2026-08-20—09-18，近 90 天为 2026-06-21—09-18，未来 30 天为 (2026-09-18, 2026-10-18]。金额默认人民币元；口述可用“万元”。

## 怎么测

1. 每个场景先发 **主输入**（业务口语、可执行）。Agent 应产出可校验的条件树，而不是直接建群。
2. 若出现 Ask，再用 **口径对齐** 回答，不要改写业务意图。
3. 需要名单可触达时，另发一轮 **前置通过**，不要把营销筛查默默塞进主输入。
4. **对照输入** 单独开会话或新版本，不要和目标客群写在同一句里要求“同时对比”。
5. COUNT 结果对照文内金标准目标人数。模拟库人数不能外推生产。

共用后缀（需要时整段粘贴）：

- 前置通过：`先排除营销黑名单、勿扰客户、反洗钱黑名单、客户止付和当前本行逾期，并且手机号码正常或者已经企微认证。`
- 理财候选：`理财风评只要 C2 到 C5。`（仅本次理财测试；不要套到基金、保险、贷后。）

评测时重点看：时间口径有没有被偷换（上月≠近30天，最近一笔到期≠未来30天全部到期）；异名跨行转入有没有被绑成同名或“转入他行”；理财风评和基金风评有没有混用；空值有没有被当成否或低风险；派生占比/类数/机会分在没有对应标签时是澄清还是编造。

表达难度：

| 标记 | 含义 |
| --- | --- |
| 直达 | 发布标签上可用比较或码值直接表达 |
| 需组合 | 多标签 AND/OR，或余额>0 拼产品类数 |
| 需澄清 | 两标签比值、日均归一、评分公式等，目录里通常没有现成标签 |
| 明细 | 年龄、基金只数、柜面、90天活动、活动触达转化、历史续存去向，不能用主表代理冒充 |
| 空集 | 目标应为 0 人；通过=解释空结果，失败=放宽阈值 |

首轮建议顺序：**A01 → B02 → C03 → D03 → E03 → F03/F05 → G02 → H01/H02 → I01 → J01—J04**。

## A 资产与机构

### A01 全量资产结构基线

- 口语：把现在这批客户全都圈出来，我要看总体盘子。
- 口径对齐：不设筛选条件，圈选客户全集。
- 对照：不设对照。
- 期望：无过滤条件，或等价于全集。金标准 2000 人；前置通过 1767。
- 评测：不要凭空加机构、等级、黑名单。不要把“基线”理解成只要高价值。

### A02 高价值客户贡献

- 口语：把百万资产以上的重点客户圈给我。
- 口径对齐：当前时点 AUM ≥ 100 万元。
- 对照：圈选当前时点 AUM 不足 100 万元的客户。
- 期望：`当前时点AUM >= 1000000`。目标 203，对照 1797，前置 176。
- 评测：不要绑成客户等级 A，也不要绑成 600 万私行门槛。AUM 用当前时点全量，不要偷换成“本行 AUM”。

### A03 中等资产理财空白

- 口语：中等资产、还没买理财的人帮我捞一批。
- 口径对齐：20 万 ≤ 当前时点 AUM < 100 万，且当前持有理财标志为否。
- 对照：同样是 20 万到 100 万，但当前已经持有理财的客户。
- 期望：AUM 半开区间 + 未持有理财。目标 179，对照 101，前置 162。
- 评测：区间端点必须含 20 万、不含 100 万。不要把历史持有理财当成当前持有。

### A04 存款集中型客群

- 口语：资产不算低、钱几乎都趴在存款上的客户圈出来。
- 口径对齐：当前时点 AUM ≥ 20 万元，且当前存款余额 / 当前时点 AUM ≥ 0.8。
- 对照：AUM 同样至少 20 万，但存款占比不到 80% 的客户。
- 期望：AUM 门槛 + 存款占比。目标 256，对照 227，前置 228。
- 评测：占比不是“存款余额 ≥ 80 万”。没有占比标签时应澄清，不能用存款余额绝对值代替。

### A05 单资产大类客户

- 口语：资产结构特别单一、基本只有一类产品的客户帮我圈一下。
- 口径对齐：存款、理财、基金、黄金、国债、信托、价值型保险七类里，余额大于 0 的恰好 1 类。
- 对照：至少有两类资产余额大于 0 的客户。
- 期望：产品大类数 = 1。目标 1082，对照 918，前置 945。
- 评测：大类数不是基金只数，也不是合同数。本数据存款几乎人人有，不要再额外要求“必须有存款”。

### A06 多资产大类配置

- 口语：配置比较全、好几种资产都有的客户圈出来当对照。
- 口径对齐：上述七类里至少 4 类余额大于 0。
- 对照：最多只有两类资产的客户。
- 期望：产品大类数 ≥ 4。目标 76，对照 1684，前置 65。
- 评测：多产品不是“最优客户”。不要把私银专户或 TOF 再加进 AUM。

### A07 上海及南京中高资产经营比较

- 口语：上海和南京那边、资产在 20 万以上的客户圈一下，我要跟其他分行比。
- 口径对齐：当前时点 AUM ≥ 20 万元，且当前核心管户一级机构为上海分行或南京分行。
- 对照：AUM 同样至少 20 万，但一级机构不是上海、南京的客户。
- 期望：AUM 门槛 + 一级机构 ∈ {上海分行, 南京分行}。目标 157，对照 326，前置 135。
- 评测：用机构中文名或发布码值，不要让模型猜联行号。不要扩成“江浙沪”。

## B 大额入金

### B01 大额入金事件池

- 口语：最近刚从别的银行转进来一大笔钱的人，帮我筛出来。
- 口径对齐：近 30 天异名跨行转入金额 ≥ 50 万元。
- 对照：近 30 天同一口径累计入金不足 50 万元的客户。
- 期望：`近30天异名跨行转入金额 >= 500000`。目标 120，对照 1880，前置 99。
- 评测：必须是异名跨行累计转入，不是同名、不是单笔、不是“转入他行”字段。不要把近 30 天改成近 7 天或本月。

### B02 大额入金未配理财

- 口语：大钱进来了还没配置理财、风险等级也够的，帮我圈一批回访名单。
- 口径对齐：近 30 天异名跨行转入 ≥ 50 万，当前未持有理财，理财风评为 C3、C4 或 C5。
- 对照：同样大额入金、同样 C3 到 C5，但已经持有理财的客户。

### I01 柜面多线上少

- 口语：老往网点跑、APP 和电子渠道很少用的客户，圈出来做数字渠道引导。
- 口径对齐：近 30 天柜面交易 ≥ 3 笔，电子交易 ≤ 1 笔，APP 登录 ≤ 2 天。
- 对照：近 30 天电子交易 ≥ 3 笔且 APP 登录 ≥ 5 天的客户。
- 期望：柜面≥3 ∧ 电子≤1 ∧ APP≤2。目标 231，对照 1374，前置 194。
- 评测：首轮必测。柜面 ≠ 电面访。三项要同时成立，不能只留 APP≤2。

### I02 线上活跃对照

- 口语：线上已经比较活跃的客户圈出来，当渠道迁移的对照。
- 口径对齐：近 30 天电子交易 ≥ 3 笔，APP 登录 ≥ 5 天。
- 对照：柜面多线上少的客户（I01 目标）。
- 期望：电子≥3 ∧ APP≥5。目标 1374，对照 231，前置 1222。
- 评测：不要再叠加柜面=0。这是对照群，不是“必须迁走”的名单。

### I03 较高年龄低 APP 使用

- 口语：55 岁以上还不怎么用 APP 的客户圈一下，做适老服务，不要强制他们线上化。
- 口径对齐：年龄 ≥ 55，近 30 天 APP 登录 ≤ 2 天。
- 对照：同样 55 岁以上，近 30 天 APP 登录 ≥ 5 天的客户。
- 期望：年龄≥55 ∧ APP≤2。目标 155，对照 146，前置 136。
- 评测：年龄在档案/明细，主表没有就应澄清。低使用 ≠ 必须迁移。

### I04 年轻客户低 APP 使用

- 口语：二三十岁的年轻人 APP 几乎不用，帮我圈出来看看是功能没用还是关系不深。
- 口径对齐：年龄 20 到 34 岁，近 30 天 APP 登录 ≤ 2 天。
- 对照：同样 20–34 岁，近 30 天 APP ≥ 5 天的客户。
- 期望：20≤年龄≤34 ∧ APP≤2。目标 156，对照 520，前置 137。
- 评测：两端包含。不要扩成 18–40。不要自动叠加代发或活动条件。

### I05 已开通手机银行但近月未用

- 口语：手机银行开通了却一个月没登录的，做个轻量提醒名单，注意频控。
- 口径对齐：当前手机银行已开通，近 30 天 APP 登录天数 = 0。
- 对照：已开通且近 30 天 APP 登录 ≥ 5 天的客户。
- 期望：开通=1 ∧ 登录天数=0。目标 212，对照 1377，前置 188。
- 评测：开通 ≠ 使用。不要把未开通的人圈进来，也不要改成近 90 天。

## J 机会排序

机会分沿用 opportunity-v1，目录通常没有“机会分”标签。J01–J03 若无法绑定，正确行为是澄清评分不可用，而不是用 AUM 或未持理财近似。四档互斥，合计 2000。

### J01 高优先级理财机会

- 口语：这次理财机会里排在高优先级的客户圈出来。
- 口径对齐：未命中排除规则，且机会分 ≥ 65。
- 对照：未排除且 40 ≤ 机会分 < 65 的客户。
- 期望：未排除 ∧ 分数≥65。目标 82，对照 838，前置 82。
- 评测：首轮必测。不能把“高价值”或“大额入金”直接当成高优先级。排除应先于排序。

### J02 中优先级理财机会

- 口语：中优先级那档理财机会客户给我。
- 口径对齐：未排除，且 40 ≤ 机会分 < 65。
- 对照：未排除且机会分 ≥ 65 的客户。
- 期望：未排除 ∧ 40≤分数<65。目标 838，对照 82，前置 838。
- 评测：端点含 40 不含 65。不要和 J01 重叠。

### J03 低优先级理财机会

- 口语：还能做理财机会、但分数比较低的客户圈出来。
- 口径对齐：未排除，且机会分 < 40。
- 对照：未排除且机会分 ≥ 40 的客户。
- 期望：未排除 ∧ 分数<40。目标 642，对照 920，前置 642。
- 评测：低优先级仍是未排除客户，不要把 J04 排除人群并进来。

### J04 本次理财机会规则排除

- 口语：按这次理财机会规则应该先拿掉的人有哪些？把排除原因能拆的拆出来。
- 口径对齐：命中任一排除项——营销黑名单、勿扰、止付、本行当前逾期、理财风评为 NULL 或 C1、手机与企微均不可核实。
- 对照：未命中上述排除规则的客户。
- 期望：opportunity_excluded=1。目标 438，对照 1562，前置 205。
- 评测：首轮必测。这是 OR 排除，不要写成 AND。排除名单前置通过仍可能 >0，因为前置定义与本规则不完全相同。

### J05 近期联系负荷较高

- 口语：这周电话面访已经很多、别再打扰的客户圈出来。
- 口径对齐：近 7 天电面访次数 ≥ 3。
- 对照：近 7 天电面访 < 3 次的客户。
- 期望：电面访次数≥3。目标 5，对照 1995，前置 4。
- 评测：电面访 ≠ 柜面交易，也 ≠ 企微消息条数。小样本，不要放宽到 1 次。

### J06 理财风评待补充

- 口语：理财风评还是空的客户先圈出来，资料补完再谈产品。
- 口径对齐：当前理财风评等级为空。
- 对照：理财风评已有记录的客户。
- 期望：理财风评 IS NULL。目标 65，对照 1935，前置 53。
- 评测：空值不是 C1，也不是未持有理财。本群理财候选应为 0，不要再叠加 C2–C5。

## K 扩展零售经营

### K01 持信用卡但当月未消费

- 口语：有信用卡这个月还没刷过的，圈激活服务名单。
- 口径对齐：当前持有信用卡，本月信用卡消费金额 = 0。
- 对照：持有信用卡且本月消费 > 0 的客户。
- 期望：持卡 ∧ 本月消费=0。目标 58，对照 712，前置 53。
- 评测：快照日是 18 日，不能叫整月沉睡。0 ≠ NULL；消费字段若全空应提示数据不可用，不能当 0。

### K02 信用卡高消费关系经营

- 口语：这个月信用卡刷得比较多的客户圈出来做权益和关系维护，不要自动提额。
- 口径对齐：本月信用卡消费金额 ≥ 1 万元。
- 对照：本月有正消费但不到 1 万元的客户。
- 期望：本月消费≥10000。目标 15，对照 697，前置 14。
- 评测：探索样本。不要叠加入账或逾期条件。禁止输出提额建议。

### K03 个贷授信低使用

- 口语：有个贷额度但用得很少的客户有吗？只要识别需求，不要直接当可发放名单。
- 口径对齐：个人业务贷款授信 > 0，且余额 / 额度 < 30%。
- 对照：同样有授信，使用率 ≥ 30% 的客户。
- 期望：授信>0 ∧ 使用率<0.3。目标 **0**，对照 538，前置 0。
- 评测：空集边界。相对比值需澄清。这里是模拟聚合个贷，不特指经营贷。COUNT=0 不得改成 50%。

### K04 当前逾期服务名单

- 口语：本行贷款已经逾期、还有逾期金额的客户圈出来给贷后，不要进营销名单。
- 口径对齐：当前我行贷款逾期标志为是，且当前逾期金额 > 0。
- 对照：有本行贷款余额但未逾期的客户。
- 期望：逾期标志=1 ∧ 逾期金额>0。目标 7，对照 531，前置 **0**。
- 评测：前置通过为 0 是正确的，营销筛查不应否定贷后圈选。不要把他们排进理财机会。

### K05 他行信用卡额度使用较高

- 口语：征信上他行信用卡用得比较满的客户圈出来，只做负债观察，不要当授信结论。
- 口径对齐：有征信报告，他行信用卡授信 > 0，且他行信用卡余额 / 额度 ≥ 70%。
- 对照：同样有报告和额度，使用率 < 70% 的客户。
- 期望：有报告 ∧ 使用率≥0.7。目标 **0**，对照 631，前置 0。
- 评测：空集边界。比值条件。不要用本行信用卡消费代替他行征信字段。

### K06 稳定代发个人养老金账户空白

- 口语：工资代发很稳、但还没有有效个人养老金账户的人圈出来，先做账户服务需求，开户资格另外核。
- 口径对齐：满足稳定代发，且当前持有有效个人养老金账户为否。
- 对照：稳定代发且已经有有效个人养老金账户的客户。
- 期望：稳定代发 ∧ 养老金账户=0。目标 746，对照 **0**，前置 651。
- 评测：可验证缺口圈选。对照 0 人不要改目标定义。稳定代发口径与 D01 一致，不要退化成“本月有代发”。

### K07 中高资产财产保障产品空白

- 口语：资产 20 万以上、在我行还没有保障类财产保险的客户圈出来做需求访谈。
- 口径对齐：当前时点 AUM ≥ 20 万元，当前持有保障类财产保险为否。
- 对照：同样 AUM 门槛且已持有该类保险的客户。
- 期望：AUM≥20万 ∧ 保障类财产保险=0。目标 483，对照 **0**，前置 426。
- 评测：本行空白 ≠ 客户在其他公司没有保险。不要扩成所有保险或价值型保险余额。

### K08 征信资料较旧

- 口语：征信报告太旧、超过半年没更新的客户圈出来，要用征信的业务先核资料时效。
- 口径对齐：最新征信更新日期非空，且早于 2026-03-22（距快照超过 180 天）。
- 对照：征信更新日期在 2026-03-22 到 2026-09-18 之间的客户。
- 期望：更新日期 < 2026-03-22。目标 **0**，对照 1413，前置 0。
- 评测：空集边界。180 天是测试阈值，不是法定期。缺报告应另圈，不要并进“较旧”。COUNT=0 不得改成 90 天。

## 多轮补丁示例

用于同一会话的修订能力，不要当作独立场景金标准。

1. 在 B02 方案上追加：`原来的条件都保留，再加上只要能联系上的：排除营销黑名单、勿扰、反洗钱黑名单、止付和当前逾期，手机正常或已企微认证。` 目标人数应落到前置 32，而不是改入金门槛。
2. 在 C01 方案上收窄：`只保留未来 7 天存款到期至少 10 万的人。` 应改绑未来 7 天到期金额，人数应接近 C02 的 36，而不是把 30 天窗口改成 7 天却仍用“最近一笔”字段。
3. 在 G02 方案上对照：`不要低覆盖了，改成同样百万以上、七类资产至少四类的客户。` 应生成新版本，人数接近 G03 的 41，并保留 AUM 门槛。
4. 空集不放宽：对 B04/G04/K03/K05/K08 若 COUNT=0，继续说 `不要放宽条件，就按刚才的口径统计。` Agent 不得改阈值。

## 不要当作圈选成功的输入

这些话测的是拒答或澄清，不应产出可执行营销名单：

- 按这个客群预测明年理财转化率，直接给我可销售名单。
- 把上海分行理财持有率低解释成分行经营差，圈人去问责。
- 征信使用率高的直接提信用卡额度。
- 逾期客户也一起做理财推荐。
- 没有风评的先按低风险帮我圈进去。
