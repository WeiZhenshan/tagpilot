## 2. 生成前的总体分层设计

金额：元，保留两位小数；内部使用整数分。AUM采用分层截断对数正态，避免均匀分布和单点模板。

| AUM范围 | 期望权重 | 分层中位参数（元） |
| --- | --- | --- |
| 200—5万元 | 54.7% | 12,000 |
| 5万—20万元 | 21.9% | 88,000 |
| 20万—100万元 | 13.2% | 440,000 |
| 100万—600万元 | 7.1% | 2,100,000 |
| 600万—2500万元 | 3.1% | 9,100,000 |

权重是期望，实际允许波动。生成“年龄/收入/资产层/风险/渠道偏好/代发关系/活跃状态/机构”的共同画像，再依条件概率生成产品持仓和事件，最后聚合标签。客户群可以交叉，不预先将2000人均分为八组。客户等级A/B/C与资产正相关，但允许综合贡献偏移；A最高、100万/20万分界均为本次模拟约定，原码值只定义A/B/C字面含义。私行600万元门槛也仅是模拟参数。

## 3. 财务与字段相关性

- 主AUM=存款+理财+基金+黄金+国债+信托+价值型保险。余额均为本行人民币等值；本次未模拟外币、在途、养老金、三方存管等余额，相关明确无余额字段为0。
- 存款=活期+定期；普通定期六种期限加总=定期总额；大额存单/结构性/通知存款为0，因此本次不会产生重复归属问题。
- 基金=货币+债券+混合+股票+QDII，等于公募基金；非货币基金是其子集，不能再次加入AUM。基金成本+累计收益=当前市值；累计收益与收益率允许负值。
- 理财按投资类型和发行人有两种分类，分别加总到同一个理财总额，不能把两套分类相加。
- 三类AUM占比属于本次模拟风险桶：现金=活期存款+现金管理理财+货币基金；权益风险桶=股票/混合/QDII基金+黄金；固收桶=剩余资产，含定期、稳健理财、债券基金、国债、信托和价值型保险。该桶分类不是监管标准或原表已说明的权威口径；正式落地可优先直接展示产品大类金额，混合基金/信托需要真实底层穿透口径再替换。
- 高资产客户平均产品种类增加，但通过配置缺口画像降低部分客户的理财/基金持有率。风险承受能力较低客户优先货币/债券类；保留少量历史购买时匹配、当前评估下已不匹配的存量基金，用于适当性排除测试，不作为新增销售机会。
- 收入采用随AUM上升的对数正态分布，仍保留收入与资产不一致；工资按税前收入的约78%与月度噪声模拟，无税法含义。
- 近期入金大概率提高现金与存款集中度；工资下降同时降低近期渠道活跃概率；沉睡画像排除近期代发，避免“无交易但每月仍有工资入账”的矛盾。
- APP日活、转账时间窗口由明细聚合；近7/30天包含快照当天，上N个月为之前完整自然月；本月只有18天，不能直接与完整上月数量判定下降。
- 机构规模不均，采用10家一级机构及其城市名称明确的二级机构。没有父子关系证明的三级机构为NULL，未使用全码表覆盖率冒充客户地域代表性。

## 6. 目标、对照与隐藏规律

大额入金未配理财目标与已配理财对照按同风险等级、同AUM区间、log(AUM)距离<=0.5做无放回最近邻配对。报告匹配覆盖率、未匹配人数、配对存款占比差和固定种子Bootstrap区间。不强制所有目标都能匹配，不把简单全行平均差解释为经营差异或因果。

预设方向：入金未配置客户存款集中；年龄增加电子活跃概率降低；高资产仍可能沉睡；收入下降伴随活跃下降；机构经营概率存在温和差异；高价值客户活动响应更高。只有最终统计确实观察到的规律才进入校验报告。某些机构差异可能被小样本随机噪声覆盖，不能宣称预设机构一定最差。

反人工化：有条件概率而非确定映射；真实码值不均匀采样；金额长尾；目标不互斥；随机种子固定以便复现；例外用于缺口或存量风险识别；不会新增“机会等级”“场景结论”等主表列。

## 7. NULL、零和专项边界

逐列定义、类型、分类、合法码值、生成规则、实际NULL率见《970字段字典》。0代表本模拟明确无该余额/事件/专项产品；NULL代表不适用或缺少可核实口径，不等于0。三方存管、部分专属卡、历史专项、复杂贷款、受理点埋点、黑盒预测分数等不会以无依据随机值补齐。

主表明确生成613列（其中少数条件列在本样本均不适用）；其余字段保留NULL。这个交付用于约定经营场景，不声称覆盖970个标签全部业务功能。字段字典列出了每个字段的处理策略，核心资产、产品、风险、入金、机构、代发和活跃字段具有实际样本。

可选补充表以SIM_前缀隔离：客户年龄/收入与资产桥、基金持仓、13个月工资、到期处置、一次历史活动、每日渠道、转账事件、产品购买事件。它们不是原宽表已有字段；只有执行08文件才会建这些表。模拟事实支持场景验证，不是完整银行复式记账流水，也不用于真实适当性或税务判断。
