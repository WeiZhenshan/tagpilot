# 标签评测通用事实规则

本页属于可复用的来源解释规则；不保存题目组合、阈值答案、客户人数或命中集合。当前为从仓库提炼的知识草稿，未获业务签署。

- 基础字段与业务类型取自标签库、原始说明及 DDL；语义类型、单位、倍率和时间/统计口径还需与发布快照交叉核对。来源互相冲突时保留 UNRESOLVED。
- `VERIFIED_SOURCE` 仅代表来源可对应；Demo 码值约定与已复用来源分别标注。已审核状态不是口径正确的独立证据。
- 码值以字符串保留，`03` 不等于 `3`。NULL 不等于 0、否、空字符串或未持有。
- 当前、历史、近 N 天、自然月、期末、日均、累计、最高、本行/跨行、同名/异名是不同口径，不能通过近义表达互换。
- “高”“活跃”“优质”等词在没有明确规则时需要澄清。用户给出的数值只属于当前需求，不自动变成全平台默认值。
- 标签引用必须符合当前运行资格及发布能力；缺少时可解释能力缺口，但不得静默删条件或跨资格使用。
- 完整 ID 集相等比人数相等更严格。模拟 SQL 的预期结果不能外推为实时数据库内容一致或银行数据验收。
- 活动快照、索引、来源文件、日期及模型版本共同确定一次实验；旧报告不能自动证明新版本质量。

来源导航：`data/p0-v1/manifest.json` 给出各来源位置与 hash；`facts.jsonl` 保存字段级证据；`issues.jsonl` 保存未解决冲突。此处不重复具体案例真值。
