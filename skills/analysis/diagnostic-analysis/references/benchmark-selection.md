# 基准选择

## 基准类型

| 类型 | 说明 | 适用 |
| --- | --- | --- |
| `same_aum` | 同资产层级客群 | 防"资产规模差异"混淆产品行为差异（默认） |
| `all_customers` | 全量客户 | 看客群相对全行的位置 |
| `same_org` | 同机构（分行/支行） | 排除地域经营差异 |
| `standardized` | 标准化基准 | 按 AUM × 风险等级交叉标准化后比较 |

选择顺序：先 `same_aum`（最能隔离产品行为差异），需要看全局位置时补 `all_customers`，机构维度有明显差异时补 `same_org`。

## 可比性检查清单

比较前逐条确认，任何一条不满足就要么换基准、要么声明不可比：

- **同期**：两侧数据日期一致（`data_as_of` 对齐）。
- **同口径**：指标定义一致（分子分母、时间窗口、是否含无资产客户）。
- **同分母**：比率类指标的分母口径一致。
- **样本充足**：两侧样本都超过抑制阈值（20），统计比较时按检验方法要求更高。

## 基准不可用时的处理

本轮尚未接入基准取数通道。此时：

1. 在 `reasons` 中写「缺少基准数据，无法量化差异」。
2. `comparison` 段如实写未接入，`benchmark_fact_ids` 与 `difference_fact_ids` 留空。
3. 诊断段可以给出**检验计划**（接入什么基准、口径如何对齐）作为 `HYPOTHESIS` 级内容？——不：计划不是诊断，写在 `followups` 里。
4. 不要把"和正常情况应该差不多"之类的直觉写成结论。

## 差异表达

- 比率差用 **pp**（百分点）：`48.7% − 23.4% = 25.3pp`；相对差才用 %（`相对低 52%`），两者不能混用。
- 金额差注明单位与是否可比期间。
- 标注方向：缺口（低于基准）还是溢出（高于基准），并且**方向本身不做价值判断**——高与低都不等于好与坏。
