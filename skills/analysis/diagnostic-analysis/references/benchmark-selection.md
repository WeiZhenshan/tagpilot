# 基准选择

## 基准来源

| 来源 | 说明 | 适用 |
| --- | --- | --- |
| `baseline` 对照客群（已接入） | 用户在运行前选择的已保存客群，服务端按同一批标签列重新编译并统计；`benchmark.*` 是对照值，`diff.*` 是差值 | 默认来源；在报告里写清对照客群名称与人数 |
| `same_aum` | 同资产层级客群 | 防"资产规模差异"混淆产品行为差异 |
| `all_customers` | 全量客户 | 看客群相对全行的位置 |
| `same_org` | 同机构（分行/支行） | 排除地域经营差异 |
| `standardized` | 标准化基准 | 按 AUM × 风险等级交叉标准化后比较 |

优先使用上下文里的 `baseline`——它是本轮唯一可复核的服务端基准。上下文没有 `baseline` 时，`same_aum` / `all_customers` / `same_org` / `standardized` 都是**尚未接入取数通道**的类型：在 `reasons` 中写「缺少基准数据，无法量化差异」，`comparison` 段如实写未接入，`benchmark_fact_ids` 与 `difference_fact_ids` 留空；诊断段只允许规则型结论（规则原文写进边界）。

## 可比性检查清单

比较前逐条确认，任何一条不满足就要么换基准、要么声明不可比：

- **同期**：两侧数据日期一致（`data_as_of` 对齐）。
- **同口径**：指标定义一致（分子分母、时间窗口、是否含无资产客户）。
- **同分母**：比率类指标的分母口径一致。
- **样本充足**：两侧样本都超过抑制阈值（20），统计比较时按检验方法要求更高。
- **截断声明**：任一侧该列被自身圈选条件截断（`plan_tag`）时，差异结论必须声明截断影响。

## 差异表达

- 比率差用 **pp**（百分点）：`48.7% − 23.4% = 25.3pp`；相对差才用 %（`相对低 52%`），两者不能混用。
- 金额差注明单位与是否可比期间。
- 标注方向：缺口（低于基准）还是溢出（高于基准），并且**方向本身不做价值判断**——高与低都不等于好与坏。
- 与对照客群的差异是观察事实；把差异诊断为"问题"需要规则或检验支撑，`basis` 按依据如实填写。
