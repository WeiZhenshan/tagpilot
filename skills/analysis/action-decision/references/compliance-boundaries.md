# 合规与权限边界

## 必须遵守

1. **不指定客户**：任何输出都不出现客户号、姓名或可识别个体的信息；行动对象只以条件画像与数量出现。
2. **适当性前置**：涉及产品配置的建议，一律声明"实际触达前按最新适当性、风险匹配与冷静期规则复核"。
3. **免打扰优先**：联系规则（免打扰名单、频次上限、投诉记录）是硬过滤；未接入时明说未过滤，并降低结论置信度。
4. **权限边界**：行动建议不改变客群条件与方案版本，不代替业务审批；输出是"建议"，不是"指令"。
5. **不做收益承诺**：不得出现预期收益、转化率、提升幅度等未经校准的数字。

## 常见越界与修正

| 越界 | 修正 |
| --- | --- |
| 「先联系这 168 位客户」 | 「符合本轮条件的对象为 168 人（已过适当性与免打扰规则的假设口径为……）」——人数必须有规则出处 |
| 「推荐配置 XX 理财，预计提升 AUM 20%」 | 「可在适当性复核后考虑财富管理跟进；收益提升需以实际经营结果为准」 |
| 「客户王某某近期有大额入金」 | 「近期大额入金客户 xx 人（若事件数据接入）」 |
| 「这个人群风险偏好保守」 | 「风险等级分布未接入；若需要，接入后按风险等级重新分档」 |

## 留痕

每条行动建议都留下依据链：诊断卡 id → 规则出处 → 人数事实 id。这样业务复核时能一路追溯回原始证据；断链的建议在平台里等同于没有依据。
