# 选图规则

意图确定后的具体选图与结构化规则。

## 按意图选图

| intent | 首选 | 备选 | 升级为备选的条件 |
| --- | --- | --- | --- |
| `single_value` | kpi | table | 需要同时看多个单值时，拆多张 KPI 或一张 table（table 非矩阵，`column` 必须为 null） |
| `compare_categories` | bar | table | 类别 >12 或需要精确读数时用 table/截断 |
| `show_composition` | stacked_bar | table | 各组不可加、或有抑制格子时降级 |
| `show_distribution` | bar | table | 分箱需要精确读值时用 table |
| `show_matrix` | heatmap | table | 只有一维数据时降级为 bar |
| `show_conversion` | funnel | table | 不单调或各层口径不一致时禁止漏斗，改文字说明 |

## 方向与排序

- 类别名多为中文长词（"个人养老金"、"结构性存款"）→ `horizontal`。
- 强调排名 → 按数值排序；强调固有顺序（时间、层级）→ 保持自然顺序。
- 排序变化要在说明里写明（"按降序排列"）。

## 规模约束（与守卫一致）

- 类别 ≤12、系列 ≤8、格子 ≤100/系列、标注 ≤8。
- 超限的处理顺序：① 截断到业务最关键的类别并说明；② 降级为 table；③ 不画。

## 百分比结构

占比堆叠要求：每个类别一条 `percentage` 对账（引用该类别全部格子，合计 100）。如果某项占比没有分母事实，就不要把它放进堆叠——换成绝对量（人）的堆叠或删除该项。

## 漏斗

只在以下全部成立时画：

1. 每一层人数都是 AVAILABLE 事实（同一口径）；
2. 逐层单调不增；
3. 有一条 `funnel` 对账与展示顺序完全一致。

任何一层靠推算（"约 xxx 人"）→ 不画漏斗。
