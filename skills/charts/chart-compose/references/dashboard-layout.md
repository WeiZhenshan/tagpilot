# 仪表板版式

三类版式对应三步分析链路。版式不是"模板套壳"，而是把信息顺序固化成读者熟悉的节奏。

## 概览版式（客户是什么样）

```
[KPI 行]  客群规模等 1~3 个关键数
[结构/分布]  1~2 张（分布柱状 / 构成堆叠）
[明细]  可选 1 张 table
```

适用：fact-analysis 的产出配图。

## 诊断版式（哪里值得关注）

```
[KPI 行]  核心差异值（pp / 元），没有基准时不放
[对比]  客群 vs 基准的条形图
[下钻]  差异集中方向的矩阵或分组条形
```

适用：diagnostic-analysis。差异图放在对比图之后，形成"先看差异、再看它集中在哪"的阅读路径。

## 行动版式（接下来做什么）

```
[KPI 行]  可执行对象数（没有规则链时省略）
[漏斗]  候选 → 过滤 → 可执行的逐层收窄
[明细]  优先级分布 table
```

适用：action-decision。

## 信息顺序（总原则）

```
KPI（结论性数字）
   ↓
差异 / 趋势（和谁比、变化方向）
   ↓
结构 / 原因（由什么构成、集中在哪里）
   ↓
明细 / 行动对象（要做什么、从谁开始）
```

任何版式都遵守这个从上到下的抽象度递减。把明细放最上面会让读者先陷入细节。

## 平台渲染约定

- `kind="kpi"` 的图由面板统一置顶成 KPI 行，其余按 `charts` 数组顺序排列——KPI 在数组里的位置不影响展示，但为可读性仍放最前。
- 每张图有独立的标题与导出按钮；标题应能脱离上下文单独看懂（"产品持有率对比"而不是"对比图"）。
